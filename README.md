# きっぷで10

切符の4つの数字と ＋−×÷ で10を作る、1日5枚の数字パズル。

- 遊ぶ: https://satou-aaaaa.github.io/kippu-10/
- 数字を押す → ＋−×÷ を押す → もう1つの数字を押すと、2つが1つの数になります。最後の1つが10になれば改札を通れます。とちゅうで分数やマイナスになってもかまいません。
- 今日の5枚（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（難所の3枚・ヒントなし）、好きなだけ遊べる練習と「とことん」、通った切符が並ぶ切符帳（同じ切符でちがう式をさがす別解さがし）があります。時間制限はありません。
- 出てくるのは、4つの数字の組 715通りを全部解いて、10が作れると確かめた 552組だけです。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（切符の数字と式は入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
```

切符の組と解き方は `node tools/make-data.cjs` で作ります（決まりは AGENTS.md）。
